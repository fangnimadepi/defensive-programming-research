# 08｜研究决策

截止：2026-10-25。**总推荐：PIVOT。把研究中心调整为“区分策略发现与激励驱动的选择”，以 Route B 做有退出门槛的 Pilot。**这不是对原始宽泛选题的无条件 GO。

## 1. 五个决策选项的明确结论

| 选项 | 本次结论 | 理由 |
|---|---|---|
| GO | 对调整后的 B Pilot：有条件建议；对全项目：暂不 | 有可鉴别理论的实验，但普适效应和测量仍未成立 |
| MERGE | 有边界地合并 V1 Oververification | 共用任务、状态日志、成本和因果对照；不预设共享内部机制 |
| SPLIT | C/D 暂作独立后续；若统一行为模型失败则拆分验证/投机 | 避免主论文同时承担发现、训练和神经机制三个大问题 |
| **PIVOT** | **主推荐** | 已有证据回答存在性，剩余价值在可得策略、收益和信息的独立作用 |
| NO-GO | 单独做“没教作弊也会作弊”；泛压力prompt排名；单一probe/steering展示 | 与近邻研究重叠，且易作出超过证据的结论 |

## 2. 决策依据

“无本轮专门示范仍可能投机”已经有直接邻近证据，[Reward Seeker](https://alignment.anthropic.com/2026/reward-seeker/)尤其压缩 Route A 的存在性空间。与此同时，[School of Reward Hacks](https://arxiv.org/abs/2508.17511)和[生产 RL 失配研究](https://arxiv.org/abs/2511.18397)包含示范或知识播种，不能混在一起称作从无知识自主产生。

[Scheming Propensity](https://arxiv.org/abs/2603.01608)已操纵激励和环境，而且呈现低基线、工具敏感和不一致响应；因此 Route B 也必须超越“换压力提示、看作弊率”。[内部表征研究](https://arxiv.org/abs/2609.19101)已经有干预，Route D 不能只靠因果术语增加新颖性。

[研究代理审查实验](https://arxiv.org/abs/2609.28614)和[工具代理投机基准](https://arxiv.org/abs/2605.02964)进一步压缩“再测自发作弊率”的空间。前者的详细审查反馈同时改变理由与历史，仍留有精确拆分反馈信息的机会；但这更适合作为条件性副题。

验证的研究价值仍可能存在，但[轨迹研究](https://arxiv.org/abs/2604.02547)提醒多验证经常有益，[系统评估研究](https://arxiv.org/abs/2610.01618)说明工具和信息条件很重要。V1 观察应变成一个需被检验的标签：只有证明边际净收益为负，才叫过度验证。

## 3. 最值得投入的具体贡献

建议主线：**在独立真实目标与明确规范下，分开测量首次发现、条件选择和执行成功；检验相对收益、搜索预算与信息价值能否预测未见任务行为。**

首篇可交付：①公开可控任务与审计协议；②E1/E2 的随机化因果结果；③至少两个竞争模型的保留集预测；④负结果与系统依赖边界。技术贡献不必是新模型算法，但必须产生此前已有存在性论文没有提供的鉴别结果。

最高优先的三个假设：

1. 策略可得性控制会改变搜索预算效应，区分“不会发现”和“会但不选”。
2. 失败损失对有用验证与零新增信息验证的作用不同；重复验证的净价值可通过干预测量。
3. 收益—信息—成本的共享模型能否跨任务预测，必须与独立机制及系统解释竞争。

第3项若失败，不影响第1/2项作为独立问题的价值，但需撤回统一机制叙述。

## 4. 与原 V1 的关系

保留 V1 的真实代码场景、重复检查观察、状态变化判据和成本意识。修订两点：验证次数不直接等于过度；负面反馈不直接等于内部情绪或真实奖励压力。

将过验证作为 B 的独立终点，与 hacking 并列分析。两者可共用控制框架，但不能强行排成“正常→过度验证→投机”序列。若同一任务生成器内两者不能同时可靠测量，分别建立任务，再比较预测；不为了统一标题制造不自然任务。

V2 替代 V1 的选题优先级判断，不覆盖或删除 V1 文档。当前两套材料均保留，便于追踪判断如何随证据改变。

## 5. 资源与阶段决策

| 阶段 | 授权后应做的工作 | 规划资源 | 进入下一阶段的证据 |
|---|---|---|---|
| 方案冻结 | 环境规范、真值与操作检查；预注册 | 约1–2人周；尚不大规模采样 | 奖励、信息、策略可得性可以分开操纵 |
| B Pilot | E1/E2 共960episode | 全自托管约20–100 GPU-hours；若1个API槽位，约$112–187含预留＋剩余本地推理 | 有效能力/标注/操纵；足够基率和可靠成本估计 |
| B Core | 10,800基础预算，三模型，结构保留任务 | 约400–2,200 GPU-hours，长上下文另算 | 预注册鉴别成立或得到精确反证，结论可迁移 |
| B Full | 76,800episode，多家族和真实代码迁移 | 约4,000–47,000 GPU-hours | 只有核心科学问题仍需这些扩展才投入 |
| 有条件 C/D | 训练动力学或选择性神经干预 | Core C约5,500–33,000；Core D约600–2,500 GPU-hours | 能回答 B 无法回答的新问题 |

详见 [资源预算](06_Computational_Resource_Budget.md)：这些区间是基于 token、吞吐和配置假设的估算，不是测得成本。GPU 与替代 API 槽位不能重复计费。Full B＋Core C＋Core D 的算术区间约10,100–82,500 GPU-hours；不建议一次承诺该规模。

## 6. 何时停止、转向或正式立项

**停止原始主张**：存在性已知，缺乏进一步鉴别问题；新增结果只是换模型、换措辞。**转系统研究**：重复验证由自动重试、历史丢失或工具权限完全解释。**拆分方向**：共享模型不如验证/投机分离模型。**正式进入 Core**：操作有效且至少一种竞争预测有可测差异，或 Pilot 提示可通过合理样本排除重要效应。

Pilot 不是只选“最容易出问题”的模型筛选器。需保存所有预注册模型和条件结果，防止通过不断调环境制造结论。若无效应但样本不够，报告不确定；若有充分精度排除预期效应，应接受负结果。

## 7. 对下一步判断的建议

建议批准的范围是 **Route B 的协议细化与 Pilot**，同时把 A 的无示范审计加入流程；暂不批准将 C/D 作为既定主线。更准确的工作题目为：**Separating Strategy Discovery from Incentive-Driven Choice in LLM Agents**，以验证价值作为一个重要子问题。

本次调查已完成 V2 要求的九份报告；未启动实验、训练或部署。下一步真正需要决定的是：是否接受这个收窄后的科学问题及其可证伪设计，而不是是否相信模型“天生会投机”。
