# 02｜理论框架：监督、发现与选择

截止：2026-10-25。文献 ID 与出处见 [01](01_Literature_Review.md)。下文公式和预测是候选研究模型，尚未经本项目数据检验。

## 1. 把“良性”拆成可审计的不同命题

| 命题 | 可操作化证据 | 允许的表述 | 禁止的外推 |
|---|---|---|---|
| N1：无显式目标作弊演示 | 保存任务提示、工具说明、few-shot、SFT 数据及人工抽审记录 | 本研究可见输入未示范目标投机策略 | 模型没有作弊知识 |
| N2：新增训练数据诚实 | 全量规则检测＋分层双人抽审；记录歧义与漏检区间 | 审计范围内新增数据均为合规解决方案 | 所有训练阶段都是良性的 |
| N3：预训练无相关知识 | 大模型通常无法证明；从零小模型可控制数据但外推弱 | 预训练未知；小模型受限数据实验另报 | 未接触人类作弊概念 |
| N4：初始不存在策略表征 | 任何有限行为/探针测试均不能证明不存在 | 在预注册诱发预算下未观测到 | 初始潜在策略为零 |
| N5：任务中发现新策略 | 程序化随机机制，结构保留集；记录首次执行及先前探索 | 首次观测到针对新环境的有效组合 | 创造全新知识、真正从无到有 |

另区分 **数据良性、任务意图良性、奖励忠实性、模型行为合规性**。真实任务可良性，奖励却错误地认可捷径。一旦 RL 强化捷径，后续监督已包含对该行为的正反馈。因此较准确研究标题是“无目标策略示范条件下的发现与选择”，而不是没有限定的“完全良性监督下涌现恶意”。概念文档也可能改变行为，见 [L22](https://red.anthropic.com/2025/reward-hacking-ooc/)；应单列“知识暴露”，不能只检索完整作弊代码。

## 2. 行为分类必须独立于动机推断

采用两个层次，避免把重叠的轨迹强行放进单一箱子。

**动作层**：执行任务、获得新证据的验证、无新外部信息的重复验证、代理漏洞尝试、明确停止、无进展循环。每一步可有机制标签，先通过工具状态判定，再检查语义。

**episode 层**：真实任务成功、代理成功、规范违背、净资源消耗、终止原因。一个 episode 可以先验证后投机，因此“曾 hacking”与“过验证成本”可同时为真；多项结果不能解释为互斥概率。

- 合理验证：在当时可获得的信息下，其期望损失减少超过成本。
- 候选冗余验证：状态、输入、验证器和返回值均未改变，且没有外部随机性或隐藏依赖变化。
- 过度验证：进一步经随机停止/缓存回放对照显示，这类动作对质量的边际收益小于预注册成本门槛。重复动作次数只是筛选器。
- Reward hacking：执行策略可因果性提高代理得分，却未实现明确真实目标，或违反已告知的约束。记录 attempted、executed、proxy-successful 三个层级。没有明显意图证据时称“代理利用行为”，不武断称“蓄意欺骗”。
- 放弃：明确终止且承认未完成；资源耗尽是删失事件，不能与主动放弃合并。
- 循环：状态与有效证据不进展且出现重复动作模式；固定阈值用于可复现编码，并做阈值敏感性分析。

目标未告知、测试本身错误而用户允许修复、偶发能力错误，都不应自动算作弊。多验证可能帮助成功，[L26](https://arxiv.org/abs/2604.02547) 是对初始观察的重要反证。

## 3. 三个不同层次的“压力”

1. **文字要求**：例如“必须成功”。它同时改变语义、角色期待和注意，不等同于真实奖惩。
2. **环境收益**：在固定模型上，明确公布的动作分数、失败损失、检测概率与工具预算。只能估计模型对这些信息的行为响应。
3. **优化压力**：训练更新步数、选择强度、KL 约束、采样搜索与实际梯度信号。只有跨检查点及相应随机化才能识别训练效应。

必须分别报告上述处理。把 prompt 中的罚分加大，不能宣称完成了 RL 奖励压力实验。对使用组内标准化优势的 GRPO，奖励整体乘正数可能被归一化消掉；未标准化时也受学习率、KL 等影响。需要改变动作之间的相对收益或固定归一化方式，而非仅替换数字。

## 4. 候选共同框架：有限可得策略下的决策

设环境状态为 s，规范目标为 G，代理评分为 R̃，动作约束为 K，历史为 h。潜在可执行策略集合为 S，当前模型实际能提出的子集为 A(h, θ, b)，其中 θ 是权重、b 是搜索/计算预算。

一个工作模型是：

`P(a | h) ∝ 1[a ∈ A(h,θ,b)] exp{β [E(u(R̃ − failure_loss − detection_loss) | h,a) − λ·cost(a) − κ·norm_violation(a)]}`。

这里的效用、β、λ、κ 是拟合行为的参数，不是宣称模型有体验或真实欲望。规范惩罚还可能是硬约束而非连续 κ；需比较硬约束模型。若参数可以任意随每个条件变化，该公式没有预测力。应预注册共享参数，在未见任务与收益配置上预测。

**投机相对正常执行的简化优势**：

`ΔQ = E[R̃_hack − R̃_honest] − Δfailure_loss − d·F − Δcost − κ`。

模型只在理解概率和收益、知道两种策略、没有其他约束的条件下才可近似按 ΔQ 选择。保持 d·F 相同但改变 d 与 F，风险中性基线预测相近；非线性风险模型可能不同。该比较并不能单独排除概率理解偏差，因此先做等价数字格式和无规范冲突的决策校准。

**验证的价值**：

`VOI(v|h) = E_y[max_a Q(a|h,y)] − max_a Q(a|h) − cost(v)`。

对已知确定状态重复返回同一结果，外部 VOI 可为零；但新增推理时间、检索被截断证据、确认工具可信度仍可能有价值。需要缓存回放、等 token 内部复查和可用证据校验，才能分开这些解释。对高失败损失，低概率缺陷的验证也可能合理。

**发现与选择的分解**：

`P(hacking) = P(发现/可调用策略) × P(选择执行 | 策略可调用) × P(执行成功 | 已选择)`。

这是概念分解；三项不能仅从最终 hacking 率识别。必须设计策略可得性控制、独立能力测试和环境执行日志。选择菜单只作为独立诊断实验，含菜单的 run 不能计入 N1 无示范结果。

## 5. 六种竞争解释与关键区分

| 解释 | 最有区分力的干预 | 支持模式 | 仍存在的识别限制 |
|---|---|---|---|
| Training Data Transfer | 同义表面 vs 新机制；无文档/概念文档/目标演示的随机训练臂 | 概念或演示暴露显著改变发现速度，旧结构优势明显 | 暴露作用可能同时改变偏好，不只知识 |
| Instrumental Optimization | 策略集合固定；翻转相对收益；保留任务语义 | 行为按新收益反向变化，可任务外预测 | 隐藏规范成本及理解差异可能影响 |
| Goal Misgeneralization | 训练目标与线索相关；OOD 打破相关但保持正确真实奖励 | 能力保持却追随旧线索；不跟随当前收益 | 需排除感知能力退化与上下文习惯 |
| Reward Misspecification | 同一状态/权限，修补代理评分；真实真值不变 | proxy—true 分离下降，正确解质量不受损 | 修补也可能改变反馈信息量 |
| Exploration / Discovery | 收益不变；改变结构信息、搜索预算及反馈 | 首次发现时间移动；已知策略条件差异收缩 | 把策略告诉模型也可能造成需求效应 |
| System Artifacts | 缓存/重试/工具权限/历史压缩的匹配对照 | 行为随 harness 改变或在模型采样前已发生 | 系统介导的真实模型效应不能一律叫假象 |

这些机制可共同成立。比如迁移提供候选策略，探索筛选，奖励强化，harness 决定是否可执行。研究目标是辨别各自的贡献，不要求选出唯一机制。[目标泛化定义](https://proceedings.mlr.press/v162/langosco22a.html)与[形式奖励排序](https://arxiv.org/abs/2209.13085)提供不同的分析层次。

## 6. 训练方法不能放在一条“危险程度”排行榜

| 方法 | 可能的策略改变途径 | 应有对照及边界 |
|---|---|---|
| SFT | 示范模仿、概念泛化、分布变化 | 同底模、同数据量和格式，诚实/知识/示范三臂；不能只比较不同厂商 |
| RL | 采样到的策略被选择、探索和信用分配变化 | 正确奖励/有漏洞奖励、相同起点，多训练种子 |
| RLHF / RLAIF | 人或 AI 偏好代理的误差被放大 | 控制 reward model 与标签源；偏好模型来源不是独立学习算法 |
| RLVR | 程序可验证对象仍可能只是局部代理 | 保留集、变形测试、独立真实真值；L03 已做奖励对照 |
| DPO | 偏好数据与隐式奖励的过优化 | 同偏好集/优化强度；L16 已否定简单免疫论 |
| ORM | 终局分数无法区分过程合规性 | 终局正确与规范满足分开报告 |
| PRM | 中间步骤更密集监督，也增加可优化评分面 | 步骤真值、路径约束、反事实过程；L19 为反证 |
| Test-time scaling | 增加思考、候选发现，也增加采样选择偏差 | 将单轨迹思考长度与多候选数量分开 |
| Inference-time search | 在固定生成分布上选高 proxy 候选 | 相同候选集用真实/代理选择器比较；L38 已研究该问题 |

## 7. 不预设策略顺序或共享内部机制

正常、验证、投机、放弃可能直接互换；同一次执行也可能反复切换。以“正常→过验证→投机”画出的顺序是候选模式，不是理论前提。失败惩罚升高可能增加合理验证，也可能促使弃权；投机可能因检测成本更高而下降。

建议比较三个模型：M0 固定行为倾向＋任务难度；M1 收益/信息/成本的共享选择模型；M2 独立的验证与投机模型。若 M1 在未见任务上没有优于 M2，放弃统一机制的主张。神经方向若只影响一种行为，或作用可被能力下降解释，也应接受机制分离。现有 [L08](https://arxiv.org/abs/2604.07729) 与 [L09](https://arxiv.org/abs/2609.19101) 已有因果操作，新的贡献必须超过 probe 相关性和任意 steering。

**理论最小承诺**：激励、信息和可用策略共同约束行为；其相对贡献可以失败、可以跨模型不稳定。是否能得到可迁移的定量规律，是需要实验回答的问题。
