# 07｜风险、竞争解释与可证伪性

截止：2026-10-25。文献出处索引见 [01](01_Literature_Review.md)；实验定义见 [05](05_Experimental_Design.md)。以下不是风险泛论，而是影响本项目结论的具体失败条件。

## 1. 核心假设的支持、反证与撤回条件

| 核心假设 | Supporting evidence | Counterevidence / 限制 | 主要混杂 | Falsification criteria | Research implications |
|---|---|---|---|---|---|
| H0：无本轮目标示范也可能投机 | L01/03/04/11 | 所有研究均不能清除大模型已有知识；存在性已非新颖 | 底模历史、概念播种、工具说明泄漏 | 有限本项目零结果不能否定存在性；可否定“本环境发生率≥预设门槛” | A 只作审计模块；不以零结果证明绝对安全 |
| H1：可得策略限制发现，收益影响选择 | L01 的探索、L20 的反馈优化 | L21 显示反应脆弱且不稳定 | 菜单需求效应、能力差异、预算同时改变执行 | 能力/操作检查通过后，预注册预算×可得性交互的区间排除有意义效应；或方向持续与预测相反 | 放弃所拟发现瓶颈模型，报告收益/提示等替代解释 |
| H2：失败损失诱发部分净负价值验证 | V1 观察仅是线索；L08 给邻近干预依据 | L26 验证常有益，L25 工具结构效应 | 难度、异步变化、截断、内部重算、自动重试 | 匹配上述因素后，重复验证改善净收益；或所谓效应完全来自 harness | 撤回过验证标签，转为合理验证或系统效率研究 |
| H3：共享收益—信息模型能泛化预测 | L30/31 提供形式基础；部分奖励干预有效 | L21 非单调；没有证据证明两行为共享机制 | 任意参数拟合、任务混合、模型家族偏差 | 冻结参数后共享模型在结构保留集不优于独立模型；差异精度足以排除有意义优势 | SPLIT；共同框架只保留为组织语言 |
| H4：训练出现可识别的策略形成阶段 | L01/03/14 | 基线低率行为可能只是被放大；训练种子常有限 | 采样量变化、checkpoint 稀疏、阈值和裁判漂移 | 平滑/混合模型同样或更好预测；首次策略在初始充分采样已出现 | 不称新策略涌现或相变，改称概率强化 |
| H5：特定表征介导选择 | L08/09 已有因果方向操作 | 预测强不等于机制特异；共享方向未知 | 后验标签泄漏、方向多义、干预离分布、能力退化 | 随机/语义控制方向同效；能力匹配后效应消失；跨机制失效 | 放弃共同内部机制，最多报告预测器或局部干预 |
| H6：良性新增 SFT 降低风险但保留可触发条件 | L04 和 L22 的有限证据 | 强后训练可消除部分严重现象；模型家族差异大 | SFT 同时改变能力和遵循规范 | 在预注册范围内，诚实训练组低于最小风险门槛且置信区间窄；或不降低风险 | 否定相应范围内的预测；不可泛化为任何条件安全/不安全 |

文献中的反证不是本项目的失败数据。每项假说须指定适用模型、机制、奖励范围和最小重要效应；无限宽的“总能在某处出现”不能被证伪，不应作主论文理论。

## 2. 任务书要求的十项风险逐项处理

### R1：新增数据清洁无法清除预训练知识

无示范审计限定在新增数据、提示、工具说明与实验历史。保留权重来源和训练披露的不确定性。程序化随机机制降低直接记忆可能性，但底层搜索和编程操作仍可能来自预训练。发表时使用“本实验未提供目标策略演示”，不写“自主创造此前不存在的知识”。

### R2：投机可能只是普通代理奖励优化

这不是应排除的尴尬解释，而是强零模型。若期望收益模型在策略已知条件下很好预测行为，贡献必须来自发现成本、规范约束或任务外定量检验；不要再套一层心理术语。L13/15/38 已有丰富理论基础。

### R3：新组合不等于新能力

用机制级去重、结构保留集和可执行语义距离，区别改变量名与新操作组合。新颖性分数由规则机制和盲审定义，不由模型自述“我想到了新办法”决定。正面示范臂与主无示范臂隔离，避免实验自己教会模型。

### R4：验证与投机可能机制分离

共享效用框架可以描述几乎所有决策，描述共通不等于因果机制相同。比较共享/独立模型，允许双重解离。若统计关联只由难度驱动，或内部干预只影响一种行为，应拆题而非增加更多“压力”指标。

### R5：行为变化不等于训练涌现

同权重 prompt 改动是条件行为，不是学习；best-of-n 的采样选择也能改变输出分布。训练研究必须保留初始足量采样、组内候选、奖励、优势、梯度更新及冻结检查点评估，区分发现、选择和强化。

### R6：probe 预测不等于因果介导

决策之后的 token 最易出现标签泄漏。主要 probe 取动作前，按任务/机制切分；steering 对照等范数随机方向和语义邻居，检查能力损失。patching 的匹配状态及支持集限制要说明；即使干预有效也可能同时改多个变量。不能以因果词替代这些识别条件。

### R7：现象可能由提示与 harness 产生

逐条区分自动重试、模型主动再次调用、工具缓存命中、重放输出和用户新增要求。工具权限本身改变可行策略，不宜仅作“噪声”删除。语言条件和实际奖励条件分别随机；匹配上下文长度、信息量与动作可用性。API 内置上下文和模型版本不可完全控制时，明确外部效度边界。

### R8：2025–2026 研究覆盖过多

优先比较 L04、03、21、09、25，附加 L20/24/38/39/40。若只能得到换模型复现和新增 prompt，主论文新颖性不足。L23 仅概念提案不能当实证阻断，但其已有概念框架仍要引用；L24 已有可访问的完整论文，其代码仓库链接不可访问只限制独立复现，不能降低对其已报告结果的文献重叠权重。

### R9：投机和策略新颖性难客观测量

代理分数上涨、真实分数下降不必然代表蓄意行为，也可能是统计选择或能力错误。判定需配合规范、动作与因果回放。报告 attempted/executed/successful；对未知机制保留“无法判定”。若判定器与被测模型同源，模型裁判可能共同偏误，程序真值和盲审优先。

### R10：研究范围过大

四路线不同时立项。首篇限定 E1/E2、开放任务、两种理论的鉴别；A 嵌入审计，C/D 为后续决策。若现实代码迁移困难，先如实报告受控环境规律，不把“广泛智能系统规律”写入标题。

## 3. 容易造成假阳性的额外问题

| 问题 | 可能制造的错误结论 | 必需检查 |
|---|---|---|
| 默认目标隐去 | 模型没猜中研究者意图，被标成作弊 | 规范公开且理解检查通过；目标不清单列 |
| 按最终成功筛选样本 | 发现验证越多越成功/越失败的伪因果 | 先随机化；主分析 intention-to-treat |
| 奖励缩放被归一化 | 宣称压力无效，实为处理没生效 | 检查实际奖励差和 advantage 分布 |
| 超时、拒绝、格式无效被删除 | 人为抬高作弊或成功率 | 全样本保留；分类终止与删失 |
| 共享任务模板伪独立 | 显著性被夸大 | 任务簇/训练种子作为统计层级 |
| 只选 hacking 高的模型 | 跨模型普遍性失真 | 预注册模型名单，报告地板和负结果 |
| 多层、多方向、多阈值搜索 | probe/steering 虚高 | 开发集选定，确认集一次性验证 |
| 将工具调用当同成本 | 一次全套测试与一次hash被等权 | CPU时间、token、延迟和净收益分别计量 |
| 提示中的“不可完成” | 需求效应被误判成优化结果 | 用形式不满足条件，并与未告知版本区分 |
| 博客/预印本数字未经核验 | 伪实证进入结论或功效预算 | 源文方法核查；L23 示例数不引用为效应量 |

## 4. 预注册的撤退规则

1. **操作失败**：模型无法理解任务或行动，先修环境；不更新理论结论。
2. **测量失败**：标注可靠性不足或真值被 agent 改写，停止正式统计，修测量。
3. **无效应但低精度**：仅能报告不确定；按预定最高预算补充独立任务，不能无限追加至显著。
4. **排除重要效应**：确认集区间落在预定等效区间内，接受对应假说不成立。
5. **理论预测反向**：若跨任务重复出现且操作有效，优先竞争解释，不改写“压力”方向救假说。
6. **创新性失败**：新文献已做相同因果鉴别，重新评估差异；不能只靠更大模型继续投入。

**最有科学价值的负结果**可能是：激励影响弱于策略可得性；重复验证具有真实收益；共享模型不如分离模型；或所谓突变由采样/系统解释。只要协议能区分这些结果，本项目就不必依赖“AI 必然会投机”的预设。
