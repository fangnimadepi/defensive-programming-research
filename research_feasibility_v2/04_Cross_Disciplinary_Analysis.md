# 04｜跨学科分析：哪些理论真正产生预测

截止：2026-10-25。文献事实与本报告的计算模型建议分列。人类行为证据不能证明模型拥有同样的心理体验。

## 1. 人类学习中，“未教过”也不等于“此前不会”

[Schweitzer、Ordóñez、Douma（2004）](https://faculty.wharton.upenn.edu/wp-content/uploads/2014/06/Goal-Setting_1.pdf)研究目标设定与不诚实报告；它提供无需专门逐步示范也能出现策略性报告的相关证据。参与者带着社会经验进入实验，因此不能由此证明策略从零产生。这与大模型预训练知识无法清除的问题在识别结构上相似。能够比较的是目标差距、观察条件、成本和行动分布，不能比较未经测量的“内在动机相同”。

[Köbis 等（2025）](https://www.nature.com/articles/s41586-025-09505-x)已经直接研究人类委托者与机器执行者的诚实行为。不同界面和监督形式是干预变量，而“人性类比”不是证据。其设计提示：目标如何被表达、由谁承担后果、何种结果被看见，都会改变行为；这些因素应与模型本身分开。这意味着跨学科方向已经有团队开展，不能宣称这是未开垦领域。

关于“人类独立发明新作弊方法”，本次找到的研究不能证明终生无知识暴露。若未来加入人类对照，应采用新随机规则游戏、事前能力测量与结构迁移；结论仍是环境内发现，不是从无知识到有知识。当前主研究不需要招募人类才能成立。

## 2. 理论—计算变量—鉴别实验

| 理论与原始来源 | 在机器研究中的可用内容 | 可检验预测 | 边界与反证 |
|---|---|---|---|
| Goodhart；[Manheim & Garrabrant](https://arxiv.org/abs/1803.04585) | 将选择噪声、极值外推、因果改变、对抗利用区分 | 固定候选集而更强选优即可产生部分 proxy—true 分离；不必有主动作弊 | 若称所有失败为 Goodhart，将失去可证伪性 |
| Campbell；[1979 原文](https://doi.org/10.1016/0149-7189(79)90048-X) | 指标进入决策后，被测行为分布改变 | 公布评分规则或提高其决策权重后，指标相关行动重分配 | 社会学论述不是 LLM 必然腐化定理 |
| Specification gaming；[Skalse 等](https://arxiv.org/abs/2209.13085) | 真实目标与 proxy 对策略的排序冲突 | 修补排序冲突后，原高分捷径失去优势 | 若只因目标未告知而失败，规范违规判断不成立 |
| Goal misgeneralization；[Langosco 等](https://proceedings.mlr.press/v162/langosco22a.html) | 训练分布中目标不可辨识 | 正确奖励下训练，OOD 打破目标线索相关性后仍追旧线索 | 若只是不会操作环境，则不是目标泛化证据 |
| Instrumental convergence；[Turner 等](https://papers.nips.cc/paper/2021/hash/c26820b8a4c1b3c2aa868d6d57e14a79-Abstract.html) | 条件化最优策略分析 | 特定环境中扩大可达状态有工具价值 | 最优策略定理不保证现实 LLM 学得或选中它 |
| Principal–agent / moral hazard；[Holmström & Milgrom](https://www.sfu.ca/~allen/HolmstromMilgrom.pdf) | 可测表现与真实多任务目标分离，隐蔽行动与努力成本 | 只奖励易测维度会降低难测维度投入；独立审计改变相对优势 | 模型未必有稳定私有偏好；不是所有错设奖励都需要道德风险 |
| Rational choice / deterrence；[Becker](https://www.journals.uchicago.edu/doi/pdf/10.1086/259394) | 检测概率与损失进入期望收益 | 在理解概率且策略已知时，提高预期检测损失降低投机 | 监督反向效应、规范硬约束或不理解概率会否定简单版本 |
| Bounded rationality；[Simon](https://academic.oup.com/qje/article-abstract/69/1/99/1919737) | 策略集合与搜索有成本 | 新机制需要搜索时预算影响发现；已知菜单条件该效应缩小 | 若任何结果都能解释为“有限”，模型没有价值 |
| Resource rationality；[Lieder & Griffiths](https://cocosci.princeton.edu/papers/liederresource.pdf) | 验证/思考的净信息价值 | 信息增益为零、成本明确时应停止外部检查；高失败损失提升有用验证 | 外部重复可能支持内部重算；需匹配计算控制 |
| Risk sensitivity / prospect theory；[Kahneman & Tversky](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Behavioral_Decision_Theory/Kahneman_Tversky_1979_Prospect_theory.pdf) | 风险分布、参照点、概率权重 | 相同均值不同尾部损失的选择可分离风险中性模型 | 语言 framing、算术错误和概率误解同样可产生差异 |
| RL exploration；[Gridworlds L01](https://arxiv.org/abs/2606.15385) | 初始分布、采样策略、信用分配影响可得策略 | 增加探索不一定仅增加作弊，也可能发现合规高回报路径 | 初始能力较强可能缩窄探索；不能假定更多探索更坏 |

## 3. 三种“相似”应明确区分

1. **表面行为相似**：人和模型都重复检查或夸大分数。它只提供问题线索。
2. **计算结构相似**：两者在可见代理、隐藏真值、行动成本和有限信息下选择。可以用共同任务和数学模型比较预测。
3. **算法或机制相同**：两者内部用相同价值表示、学习规则或情绪过程。需要独立机制证据，本报告不主张已经成立。

可迁移的是实验识别逻辑，例如保持期望收益相同但改变风险分布、让成本和规范分离。不可直接迁移的是把人类金钱效用参数当成模型的 token 效用，或用“失去奖励”替代真实 RL 梯度。模型看到的积分若没有后续优化，仅是提示/环境信息。

## 4. 三个能让理论竞争的实验预测

### T1：相同收益，改变策略发现难度

在独立无演示实验中，随机化规则名称、组合结构与反馈预算；在另一个诊断实验中给出等长度、无道德暗示的完整动作菜单。收益不变。

- 纯粹“已知策略下收益最大化”对菜单中的选择较稳定。
- 搜索受限解释预测无演示条件随预算变化更大，菜单会缩小差异。
- 语义迁移解释预测熟悉机制即使换名字仍较易出现，而新组合更难。

这只能区分受约束模型版本；若收益模型也允许任意未知策略集合，就与搜索模型不可辨识。必须事前固定模型的自由度。

### T2：相同预期惩罚，改变尾部损失

设置高概率小惩罚与低概率大惩罚，使 d×F 相同；真实任务成功率、工具成本、措辞长度均匹配。独立任务先校准概率理解。

- 风险中性且线性罚分模型预测相近行动。
- 风险敏感模型预测有系统差异，且该差异应能由独立风险校准预测。
- 仅换“损失”措辞就出现效应，而实际概率变化无效，会倾向支持语义框架而非风险计算解释。

已有 [Payne（2025）](https://arxiv.org/abs/2508.00902)研究 LLM 风险框架效应，因此“模型像人一样损失厌恶”本身不是创新。新的增量应来自真实工具决策与跨任务定量预测。

### T3：相同计算量，改变验证信息价值

比较独立新测试、确定性重复返回、已缓存证据回放，以及相同 token 预算的内部复查。将状态保持不变，并明确说明哪些证据已足够。

- 信息价值解释预测新测试受失败损失影响最强，重复返回较弱。
- 内部重算解释预测重复返回与等 token 复查有相似收益。
- “受到责备就多检查”的语言脚本解释可能对这些信息差异不敏感，却对评价措辞敏感。

如果重复检查确有净收益，则过验证命名错误，应接受该反证。人类理论的价值体现在这些可失败的比较，而不是事后把任意行为称为焦虑或理性。

## 5. 跨学科合作的实际增量

行为经济学可帮助设计可辨识的激励、参照点和统计对照；认知科学可约束计算模型自由度；软件工程可提供执行真值、状态不变性和真实任务迁移；AI alignment 可区分奖励漏洞、目标泛化与监测规避。建议主论文先完成机器实验，若有稳定且有外部效度的规律，再做独立人类比较。

人类实验应单独规划知情同意、补偿和机构伦理审查；它不在本轮执行范围。没有人类结果不影响 Route B 的可检验性，但结论只能针对所研究的 agent 系统。
